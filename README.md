# QUEST

### Follow curiosity, not popularity.

**QUEST is a social network where you follow questions, not people.**

Built for **Frontend Odyssey — REIMAGINE SOCIAL**, QUEST explores a different model of social interaction: instead of organizing social life around followers, posts, likes, and infinite feeds, it organizes it around **questions and ideas**.

Each question becomes a living space where people can contribute perspectives, challenge ideas, build on existing thinking, and remix perspectives into something new.

## 💡 The Idea

Most social platforms are built around:

**People → Posts → Likes → Followers → Feed**

QUEST experiments with a different structure:

**Questions → Perspectives → Responses → Challenges → Builds → New Ideas**

Instead of asking:

> "Who should I follow?"

QUEST asks:

> **"What am I curious about?"**

---

## ✨ Key Features

### 🔎 Question-Based Discovery

Discover questions that make you stop scrolling and start thinking.

### 🧠 Question Spaces

Every question becomes its own social thinking space where different perspectives connect and evolve.

### 💭 Perspectives

Users contribute their own perspective instead of simply posting content.

### ⚡ Challenge

Question an existing perspective and introduce another way of thinking.

### 🧩 Build

Connect with an existing idea and develop it further.

### 🔄 Remix

Take an existing perspective and reinterpret it from a different angle.

### ◎ Resonate

Show that a perspective connects with your thinking without turning the experience into a popularity contest.

### 📝 Dynamic Contributions

Users can add new perspectives directly inside a Question Space and immediately see them become part of the conversation.

### 🧭 My Thinking

Instead of a traditional popularity-driven profile, QUEST gives users a personal trail of the questions they've explored and ideas they've contributed to.

### 📱 Responsive Experience

Designed to work across desktop and mobile screen sizes.

## 🎨 Design Direction

QUEST combines the visual language of:

* Editorial design
* Digital magazines
* Idea maps
* Experimental social interfaces

The interface uses strong typography, generous whitespace, thin borders, circular nodes, asymmetric layouts, and subtle motion to make the experience feel more like **exploring a world of ideas** than scrolling through another social feed.

## 🛠️ Tech Stack

* **React**

## 🚀 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/shashank2602s/QUEST.git
```

### 2. Enter the project

```bash
cd QUEST
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open the local application

Vite will provide a local development URL, usually:

```text
http://localhost:5173/
```

## 🏆 Hackathon

**Frontend Odyssey**

**Theme:** REIMAGINE SOCIAL

QUEST was created to explore how social interaction could work when **curiosity becomes the organizing principle instead of popularity**.

The project intentionally avoids conventional social-media mechanics such as:

* Follower counts
* Traditional likes as the primary interaction
* Infinite scrolling feeds
* Popularity-driven profiles
* Person-first discovery

Instead, QUEST focuses on **questions, perspectives, and collaborative thinking**.
